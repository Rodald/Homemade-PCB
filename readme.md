# Homemade-PCB
The goal for this Project is to manufacture PCBs at home using DIY UV photolithography.
This Repository includes two different PCB designs.

## Benchmarking PCB
The benchmark PCB includes 5 different tests:
* Trace width
* Isolation Clearance
* Light Exposure Time & Bleeding
* Drill Hole tests
* Fonts
